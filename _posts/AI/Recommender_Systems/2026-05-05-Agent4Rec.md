## 초록 
### 1. 연구 배경 및 문제의식
- 오프라인 평가 지표와 실제 온라인 성능 사이에 차이가 큼
- 이로 인해 실제 사용자의 행동, 감정, 만족도를 충분히 반영하기 어려움
- 따라서 학계 연구 결과가 실제 서비스 환경에 바로 적용되기 어려움

### 2. 연구 목적
실제 사용자처럼 행동하는 추천 시뮬레이터를 만드는 것이 목표 <br>(=Agent4Rec,  LLM 기반 사용자 시뮬레이터)<br> <br>

핵심 연구 질문 : <br>
<span style="color: blue">LLM 기반 생성형 에이전트(Agent4Rec)가 추천시스템 안에서 실제 인간 사용자의 행동을 얼마나 충실하게 모방할 수 있는가?</span>

### 3. Agent4Rec
LLM 기반 생성형 에이전트를 활용한 추천시스템 사용자 시뮬레이터 <br> <br>
- 실제 데이터셋으로 초기화된다 (예 : MovieLens, Steam, Amazon-Book 등)
<br> <br>

**[Agent4Rec의 주요 모듈]**

| 모듈 | 역할 |
|---|---|
| Profile module | 사용자의 취향, 사회적 특성, 과거 선호를 저장 |
| Memory module | 사용자의 행동, 감정, 피로도, 시스템 상호작용을 기억 |
| Action module | 추천 아이템에 대해 시청, 무시, 평점 부여, 의견 표현 등의 행동 수행 |

- 에이전트는 추천시스템이 제공하는 아이템 목록을 페이지 단위로 확인
- 추천 알고리즘은 협업 필터링 기반 방식으로 구현
- 에이전트는 추천 결과에 대해 실제 사용자처럼 반응
  
### 4. 실험 및 분석 요약 
- 실제 사용자 선호와 에이전트 행동의 정렬성 평가
- 추천 알고리즘의 오프라인 성능 평가
- 시뮬레이션 피드백을 활용한 추천 전략 개선
- 필터 버블 효과 재현
- 추천시스템 내 인과관계 분석

> Agent4Rec은 단순한 추천 성능 비교 도구가 아니라 사용자 행동을 시뮬레이션하고, 추천 과정에서 발생하는 문제를 분석할 수 있는 실험 플랫폼이라는 점에서 의의가 있다 !


## Introduction
### 1. 추천시스템의 중요성
- 추천시스템은 현대 정보 확산에서 중요한 역할을 한다.
- 사용자가 어떤 정보를 접하고, 무엇을 선호하게 되는지에도 영향을 미친다. <br>
(개인의 콘텐츠 소비 방식 형성 / 사용자 선호 변화 유도 / 정보 노출 방식 결정 / 인지 과정에 영향 등)

### 2. 기존 연구의 한계
기존 추천시스템 연구는 주로 오프라인 평가 지표에 의존하는데, 오프라인 성능이 높다고 해서 실제 서비스에서도 좋은 성능 보장은 X <br> <br>

| 구분 | 설명 |
|---|---|
| 오프라인 평가 | 과거 데이터셋을 기반으로 추천 성능을 측정 |
| 온라인 성능 | 실제 사용자가 추천 결과에 어떻게 반응하는지 측정 |
| 문제점 | 두 평가 결과 사이에 큰 차이가 발생할 수 있음 |

<br>
이로 인해 .. <br>
- 학계 연구가 실제 서비스에 적용되기 어려움
- 추천 알고리즘 개발 속도 저하
- 실제 사용자 반응을 반영하기 어려움

### 3. 추천 시뮬레이터의 필요성
실제 사용자의 의도와 행동을 반영할 수 있는 추천 시뮬레이터가 필요하다 !!
<br> <br> 그런데 최근 LLM은 인간과 유사한 언어 이해 및 추론 능력을 보여주고 있다 <br>
-> 이러한 LLM을 기반으로 생성형 에이전트를 만들어 추천 환경 안에서 가상의 사용자 역할을 수행하도록 하자 !!<br> <br>

**중요 포인트** <br>
- 개인화된 사용자 선호를 정확히 반영해야 함
- 실제 사람처럼 일관된 행동을 해야 함
- 감정, 피로도, 기억, 과거 경험 등을 반영해야 함

### 4. Agent4Rec의 전체 구조

| 구성 요소 | 설명 |
|---|---|
| LLM 기반 생성형 에이전트 | 실제 사용자처럼 행동하는 가상 사용자 |
| 추천 환경 | 추천 알고리즘이 아이템을 제공하고 에이전트가 반응하는 공간 |

<span style="background-color: #fff3cd">이 중 사용자 에이전트 부분 :</span> <br>
- 각 추천 시나리오마다 1,000개의 LLM 기반 에이전트를 생성
- 각 에이전트는 실제 데이터셋을 기반으로 초기화
- 에이전트는 세 가지 핵심 모듈 O
<br>

1.  Profile Module<br>
- 사용자의 사회적 특성, 과거 선호 저장
- 실제 인간 사용자와 유사한 사용자 초상 구성
  <br>
2.  Memory Module<br>
- 과거 시청 기록, 추천시스템과의 상호작용 기록, 감정 (사용자의 피로도 등) 등을 기억
- 선호 누적 및 감정 기반 반성 수행
  <br>
3.  Action Module<br>
- 추천 환경과 직접 상호작용
- 취향 기반 행동(추천 영화 보기, 무시하기, 평점 매기기 등)과 감정 기반 행동(시스템 종료, 추천 목록 평가, 의견 표현)을 모두 수행
<br>



<span style="background-color: #fff3cd">그리고 추천시스템 부분 : </span> <br>
미리 정해진 추천 알고리즘(LightGCN,MultVAE 등)에 의존 <br>
주로 CF 기반 추천 알고리즘을 사용하며, <br> 개방형 인터페이스를 제공해서 다른 추천 알고리즘도 쉽게 적용할 수 있다. 

### 5. 평가 방식
두가지 관점에서 평가를 진행한다. 
<br><br>

1. 사용자 관점
에이전트가 실제 사용자와 얼마나 잘 정렬되는지 평가 <br>
평가 대상 : 사회적 특성 / 성격 / 선호 / 행동의 일관성? <br> <br>
2. 추천시스템 관점
다양한 추천 알고리즘이 시뮬레이션 환경에서 어떻게 작동하는지 평가<br>
평가 지표 예 : 추천된 아이템 수, 평균 사용자 평점, 사용자 참여 시간 등
<br> <br>
** 시뮬레이터에서 얻은 에이전트 피드백은 추가 학습 데이터로 활용됨 <br>
** 이를 통해 추천 전략을 반복적으로 개선 가능
** 개선된 추천 전략은 다시 오프라인 지표를 통해 평가 <br> -> <span style="color: blue"> 전통적인 오프라인 평가와 시뮬레이션 피드백 평가를 함께 고려하는 이중 평가 방식 제안 </span> 


### 6. 추가적인 실험 진행 
논문은 Agent4Rec의 활용 가능성을 확인하기 위해 두 가지 추가 실험을 수행했다. <br><br>

1. 필터 버블 효과 재현<br>

- 사용자가 비슷한 콘텐츠에 반복적으로 노출되는 상황을 시뮬레이션한다.
- 그 결과 추천 아이템의 속성 다양성이 감소하는 현상을 분석한다.
<br>

2. 인과관계 분석<br>

- Agent4Rec을 데이터 수집 도구로 활용한다.
- 추천시스템 안에서 데이터가 생성되는 과정의 잠재적 인과관계를 분석한다.
- 이를 통해 추천 상황에 내재된 복잡한 인과 구조를 파악한다.

### 7. 주요 기여
1. LLM 기반 에이전트를 활용한 범용 추천 시뮬레이터 Agent4Rec을 개발

2. Agent4Rec의 가능성과 한계를 광범위하게 평가

3. Agent4Rec을 활용해 필터 버블 효과를 재현
