## 초록
### 연구 배경 및 문제의식
- 오프라인 평가 지표와 실제 온라인 성능 사이에 차이가 큼
- 이로 인해 실제 사용자의 행동, 감정, 만족도를 충분히 반영하기 어려움
- 따라서 학계 연구 결과가 실제 서비스 환경에 바로 적용되기 어려움

### 연구 목적
실제 사용자처럼 행동하는 추천 시뮬레이터를 만드는 것이 목표 <br>(=Agent4Rec,  LLM 기반 사용자 시뮬레이터)<br> <br>

핵심 연구 질문 : <br>
<span style="color: blue">LLM 기반 생성형 에이전트(Agent4Rec)가 추천시스템 안에서 실제 인간 사용자의 행동을 얼마나 충실하게 모방할 수 있는가?</span>

### Agent4Rec
LLM 기반 생성형 에이전트를 활용한 추천시스템 사용자 시뮬레이터 <br> <br>
- 실제 데이터셋으로 초기화된다 (예 : MovieLens, Steam, Amazon-Book 등)
<br> <br>

**[Agent4Rec의 주요 모듈]**

| 모듈 | 역할 |
|---|---|
| Profile module | 사용자의 취향, 사회적 특성, 과거 선호를 저장 |
| Memory module | 사용자의 행동, 감정, 피로도, 시스템 상호작용을 기억 |
| Action module | 추천 아이템에 대해 시청, 무시, 평점 부여, 의견 표현 등의 행동 수행 |
